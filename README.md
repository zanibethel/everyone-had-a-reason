# Everyone Had a Reason

A closed-circle psychological murder mystery aboard the luxury vessel **Meridian**.

## Project goal

This repository is the canonical source for the story as it develops. It is structured so the same story can later support:

- the finished novel
- screenplay adaptation
- short-form episodic content
- AI-assisted storyboards, imagery, and video prompts
- Claude/AI context packs that preserve continuity

## Repository structure

- `canon/` — authoritative story facts, characters, vessel logic, timeline, clues, and murder truth
- `story/CHAPTER_SPINE.md` — current POV/chapter structure and suspense handoffs
- `story/manuscript/` — drafted novel chapters
- `adaptations/` — future screenplay and short-form adaptations
- `ai/` — future continuity/style context for AI-assisted visual production

## Working title

**EVERYONE HAD A REASON**

## Core principle

The clues are real. The interpretations are wrong.

Facts can be true while the story attached to them is false. Nearly every character hides something real, but only one person keeps manipulating the truth to escape accountability.

## Canon rule

Files under `canon/` take precedence over older brainstorming notes or superseded chat ideas. Manuscript chapters should be checked against canon before major revisions or adaptations.
